# 二、产品核心定位：先明确帮用户解决什么问题

> **一句话概括：**
>
> 帮迷茫大学生把“求职准备这件混乱的事”变成一个**可管理、可追踪、可被AI辅助优化**的系统。
它主要解决 **四个真实痛点**：

### 🎯 痛点 1：项目经历不会包装
很多学生明明做过东西，但不会写成简历语言。

→ **AI 帮他把“我做了什么”变成专业项目描述。**

### 🎯 痛点 2：不知道该学什么
大家都是今天学 Java 明天学算法，完全没路线。

→ **AI 根据目标岗位生成学习路线。**

### 🎯 痛点 3：投递记录混乱
投了哪家公司、到哪轮、问了什么都记不住。

→ **提供岗位投递追踪系统。**

### 🎯 痛点 4：每天焦虑但无执行感
任务很多，不知道今天先干嘛。

→ **提供成长任务看板。**

> 这四个功能是真能服务别人的，不是假需求。

# 三、第一阶段 MVP 功能（只做最核心，必须能跑）

我们第一阶段**只做 4 个页面模块**：

### 🧩 模块 1：用户登录注册
用户能注册自己的账号，登录后保存自己的数据。

**你会学到：**
- 前端表单
- 后端登录接口
- JWT 鉴权
- 用户数据库表

### 🧩 模块 2：项目经历优化器（AI）
用户输入：

> “我在学校做了什么项目、负责什么”

系统返回：

> 一段更专业的简历项目描述。

**这是第一个 AI 亮点模块。**

### 🧩 模块 3：岗位投递追踪板
用户可以新增：

- 公司名
- 岗位
- 投递日期
- 当前状态
- 面试记录

**这会形成一个自己的求职管理看板。**

### 🧩 模块 4：学习路线生成器（AI）
用户输入：

> “我想找 Java 后端 / 前端 / 算法 / 测试”

系统生成阶段学习建议。

---

**这四个够了。**

做完就已经是一个**能演示、能上线、能写进简历的 AI Web 应用**。

# 四、技术栈（给你选最适合新手但足够有含金量的）

> 这里很关键：**不能为了炫技把自己搞死。**

### 🖥️ 前端：Vue 3
**原因：**
- 比 React 更容易上手
- 中文资料多
- 页面开发快
- 企业也认

### ⚙️ 后端：Node.js + Express
**原因：**
- JS 前后端语言统一，认知成本低
- 写接口简单
- 非常适合初学全栈

### 🗄️ 数据库：MySQL
**原因：**
- 最经典，简历认可度高
- 后面面试也常问

### 🤖 AI 接口：调用大模型 API（先用模拟也行）
后面会教你接入。

### 🌐 其他工具：
- **版本控制：** GitHub 全程版本控制
- **部署：** Vercel（前端） + Render / 本地演示（后端）
